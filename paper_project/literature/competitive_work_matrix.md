## 可防守的 Gap 候选

### G1（对应 RQ1，较强）

现有教育多智能体工作已展示专用角色协作，非教育工作也已给出等 token 的 SAS/MAS 比较。本文研究的是在“同一模型、相同输入知识、尽可能匹配生成预算”的跨文化中文教学内容任务中做角色级受控消融；这是**评价对象与任务设定**，不是已证明的文献空白，更不是“首次使用多智能体教育”。

### G2（对应 RQ2，最强但需独立评价）

文化适配、文化组件消融、L2 语用、中文会话代理和中文二语教学内容生成均已有工作。本文只可说将学习者母语文化作为显式条件，并通过 Full/NoA3 与独立 Judge/人工盲评测量显式中外语用比较角色的边际价值；不能写“仍缺”“很少研究”或“没人做文化适配”。

### G3（对应 RQ3，中等）

LLM guardrails、教育 guardrails 与生成—检索反馈污染研究均已存在。本文可研究的是教育内容进入用户与缓存前的分阶段准入：拒绝率、优质内容误杀、弱内容漏放、缓存准入和成本曲线。定位是**风险—成本评价对象不同**，不是“首次质量网关”，也不能说文献已证明本文缓存风险。

### G4（补充 KG，弱）

教育 KG、GraphRAG、标准约束生成均已有工作。若本文只有精确键检索/结构化 prompt 注入，最多称 KG-grounded/structured-knowledge-conditioned generation；只有公平 KG/NoKG 证据后才能报告补充增益。

## 可能的审稿人反驳

1. 多智能体增益只是调用次数、token、上下文或自我集成效应；因此 RQ1 必须 budget-match。
2. A3 输出直接复述评价维度，CIEval A 构成循环验证；因此需要独立 rubric/Judge 与人工盲评。
3. “母语文化圈”把国家、语言和文化本质化，可能放大刻板印象；必须允许地区/代际/个体差异并做文化背景评审。
4. A5 若不改写内容，不应声称提高平均质量；短文只可描述 `low-quality cache admission risk`，不作确认性漏放/误杀结论。
5. KG 若未执行图检索和可追踪 grounding，就不是 GraphRAG；精确键缓存也不能替代知识图谱贡献。
6. 自动 Judge 易受顺序、措辞、长度和权威偏差影响；需随机化顺序、盲化条件、报告一致性并用人工小样校准。
