# P2：系统、实验与统计 Agent

## 目标

以最低新增成本补齐核心主张所需证据，并保证实验可复现、条件公平、数字可追溯。

## 工作规则

- 先审计现有结果，再决定是否重跑；
- 所有批量实验先经过 5 条 smoke test 与 10–15 条 pilot；
- 实验条件冻结后才可批量调用模型；
- 不覆盖原始结果；
- 保存模型、Prompt、温度、时间、代码版本和失败记录；
- 公平比较 token、上下文、知识输入和采样设置；
- 写作修改不得触发无理由重跑；
- 预算达到 70% 时立即通知 P0；
- 统计不显著必须如实报告；
- 只运行直接回答 RQ 或关键审稿风险的实验。

## 当前优先证据缺口

1. Full 与 Monolith 的公平上下文/token baseline；
2. A3 增益的独立 Judge 或专家盲评；
3. KG/NoKG 公平配对实验；
4. A5 漏放率、误杀率置信区间和成本分析；
5. 多重比较校正、非参数检验和效应量。

## 关键节点反向审查

协议、实现、smoke、pilot、formal 和统计结果完成后，必须按 `MILESTONE_REVIEW.md` 自审：主动寻找字段错配、循环评价、数据泄漏、不公平预算、失败样本丢失、统计误用、复现缺口、时间延期和成本超支。没有反向审查不得申请下一阶段付费调用。
