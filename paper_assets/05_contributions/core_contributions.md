# 核心贡献

## 1. Guardrail-Gated Multi-Agent Generation 范式

提出了**防幻觉门控多智能体生成**范式 (Guardrail-Gated Multi-Agent Generation)。

与现有方法的关键区别：

| 维度 | 现有方法 (Post-hoc Filtering) | 本方法 (In-line Gating) |
|------|------------------------------|------------------------|
| 校验时机 | 生成完成后统一过滤 | 每个Agent输出后立即校验 |
| 错误传播 | 已传播到下游Agent | 在传播前阻断 |
| 校验粒度 | 整体内容打分 | 分Agent、分维度、分题型校验 |
| 模型异构性 | 通常单模型自检 | 跨模型交叉校验 (DeepSeek + qwen3.6) |
| 容错性 | 校验失败→内容丢失 | 校验失败→降级兜底，流程不中断 |

## 2. 双模型联席仲裁机制

提出了基于模型间分歧度 (inter-model divergence) 的仲裁方法：

$$\delta = \max_i |s_i^{DS} - s_i^{MM}|$$

通过设定 $\delta_{max} = 0.15$ 阈值，识别模型间的不一致性。当两个独立模型给出显著不同的质量评分时，表明内容存在争议性，触发人工审核。这与单一模型自评的方法相比，具有更高的可靠性。

## 3. 多层级防幻觉体系

建立了从词法到语义的6层递进校验：

| 层级 | 校验方法 | 校验对象 | 类型 |
|------|---------|----------|------|
| L1 词法层 | `preA5HardRulesFilter` | 拼音格式、HSK单字 | 规则 |
| L2 结构层 | `verifyA4SolverAdversarial` | 练习题可解性 | LLM对抗 |
| L3 忠实度层 | `verifyA4Grounding` | 练习题忠于阐释 | LLM裁判 |
| L4 语义层 | `verifyA2Translation` | 回译忠实度 | LLM裁判 |
| L5 客观性层 | `verifyA3Comparison` | 跨文化偏见 | LLM裁判 |
| L6 综合层 | `verifyA5JointArbitration` | 四维质量 | 双模型仲裁 |

## 4. 学习者建模创新

### 4.1 文化焦虑度单向数据流

设计了严格单向的焦虑度更新机制：
- 唯一写入入口：results API
- 唯一读取入口：数据库
- Agent不得独立计算焦虑度

解决了多Agent系统中状态不一致的核心问题。

### 4.2 L2短期记忆趋势

引入最近N轮评估记录的滑动窗口分析，提取：
- 弱项维度 (正确率 < 40%)
- 准确率趋势 (improving/stable/declining)
- 重复错误模式 (≥2次)
- 重复场景 (≥2次)

直接注入 A4 生成 prompt，实现数据驱动的自适应内容生成。

### 4.3 多维自适应向量

通过5维能力向量 + 焦虑度 + L2趋势的组合，实现：
- 内容难度自适应
- 题型配比自适应
- 母语占比自适应
- 弱项强化自适应

## 5. 知识增强生成

### 5.1 混合知识底座

$K = K_{graph} \cup K_{llm} \cup K_{expert}$

三种知识源互补：
- $K_{graph}$：结构化语义关联，不可由LLM替代
- $K_{llm}$：大规模生成内容，质量门控
- $K_{expert}$：人工审核修正，兜底保障

### 5.2 三维复合主键缓存

`(knowledge_point_id, hsk_level, scene_id)` 三维复合主键确保缓存的语义精确性，避免传统向量检索的语义漂移问题。

### 5.3 加权置信度门控

6种guardrail结果加权聚合决定缓存准入，A5双模型仲裁权重最高(0.40)反映其作为唯一实值评分方法的可靠性。

## 6. 工程贡献

### 6.1 LangGraph + 手写编排双路径

同时支持LangGraph DAG编排和手写MultiAgentCoordinator，通过环境变量切换，保证：
- 行为一致性（共享Agent实现和Guardrail服务）
- 渐进迁移能力
- 回退安全性

### 6.2 全链路容错

- Agent层：2次重试 + 指数退避 + 90s超时
- Guardrail层：异常捕获 + 安全兜底 + 单模型降级
- 缓存层：写入失败不阻塞返回 + 异步保存
- API层：分级错误码 (400/404/500/502/503)
