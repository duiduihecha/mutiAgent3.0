## 2.1 智能辅导系统与 LLM 驱动的内容生成

智能辅导系统（Intelligent Tutoring Systems, ITS）自 1970 年代 Socratic 系统以来，长期依赖"浅层"统计模型完成知识追踪与认知诊断（Chu et al., 2025）。这类模型擅长数据驱动预测，但缺乏深层语境理解，难以生成个性化、高质量的学习材料。

LLM 的出现填补了"语言"这一鸿沟：它能够生成解释、例题与反馈。然而，LLM 作为独立解决方案并不充分——Chu 等（2025）在其系统性综述中明确指出，单体 LLM 存在幻觉、缺乏长期学生记忆、多步规划能力有限三大短板。这正是从"LLM"走向"LLM Agent"的动因：通过为其包裹记忆、工具调用与规划能力，使其胜任目标导向的教育任务。

在中文作为第二语言（CSL）教学场景，Wang（2024）以西班牙母语学习者为对象，实证了 ChatGPT 作为会话代理在提升交际动机、内容准确性方面的潜力，并发现其有助于"降低跨文化障碍"。但该研究也隐含了单体 LLM 的局限：其文化相关性依赖模型自身的概率偏好，难以保证针对特定母语圈的系统化适配。本文的工作正是对这一缺口的回应——不是"用 LLM 聊天学中文"，而是"以多智能体 + 知识图谱约束 LLM 生成可教学的内容"。

## 2.2 多智能体系统在教育中的应用

### 2.2.1 从单智能体到多智能体协同

教育智能体的角色正从"单一信息提供者"演化为"辅助教学与学习的多元社会伙伴"（顾小清、郝祥军, 2025）。顾小清与郝祥军（2025）在《悟空的毫毛：正在重塑学习技术系统的多智能体》中指出，生成式 AI 推动教育智能体从"独立"走向"协同"，多重分身代理学习中的不同角色（专家、同伴、评价者），进而重塑整个学习技术系统。这一研判与本文"五智能体分工协作"的设计理念高度契合。

### 2.2.2 多智能体 tutoring 框架的实证

Sun 与 Tai（2025）提出的 **MultiTutor** 是一个面向个体学生需求的多智能体辅导框架：由管理者智能体调度内容专家、可视化、资源推荐等子智能体，借助联网搜索与代码生成产出多模态（图像、动画、交互式模拟）学习支持，并以"识别知识缺口—搭建学习支架"的方式组织教学。与基线模型在认知复杂度、可读性、深度、多样性等维度上的对比显示，MultiTutor 在质量与相关性上持续更优。其核心价值在于验证了"任务分解到专用智能体"相对"单智能体通吃"的优势——这与本文 RQ1 的消融结论方向一致，但本文进一步将协同结构锚定在跨文化中文教学这一垂直领域，并以知识图谱与质量网关强化其可控性。

### 2.2.3 教育智能体的技术框架与挑战

Chu 等（2025）的综述将教育智能体划分为**教学代理**（Pedagogical Agents，自动化复杂教学任务）与**领域专用教育代理**（Domain-Specific Agents，如科学、语言学习、职业发展）两大类，并归纳了记忆、工具使用、规划、个性化、可解释性、多智能体通信六大技术支柱，以及隐私、偏见公平、幻觉缓解、生态集成四大挑战。该综述为本文的架构设计提供了分类学参照，也印证了"幻觉缓解"与"偏见公平"是教育 LLM 系统的共性硬问题——本文的防幻觉网关（C3）即直接针对这两项挑战。

## 2.3 知识图谱增强的 LLM 生成（RAG → GraphRAG → 结构化 KG）

### 2.3.1 从 RAG 到 GraphRAG

标准检索增强生成（RAG）通过检索文本片段缓解 LLM 的幻觉与领域知识缺失，但 Peng 等（2024）在其 GraphRAG 综述中指出，传统 RAG 忽视了"数据库中实体间关系的复杂结构"，难以强调关系型知识（如"影响"关系），而在需要综合整个语料库的全局性问题上表现不佳。

Microsoft 提出的 **GraphRAG**（Edge et al., 2024）以"LLM 抽取实体—关系知识图谱 → 社区检测 → 社区摘要 → map-reduce 全局回答"的两阶段管线，显著提升了全局意义构建类问题的全面性与多样性。Peng 等（2024）进一步将 GraphRAG 形式化为"图索引（G-Indexing）—图引导检索（G-Retrieval）—图增强生成（G-Generation）"三阶段工作流，并系统梳理了下游任务、应用领域与评估方法。

### 2.3.2 结构化知识图谱对教育生成的"硬约束"

现有 GraphRAG 多用于开放域语料问答，而本文面对的是**强事实约束、跨语言、分级（HSK）**的教育生成任务。通用向量 RAG 在跨语言 embedding 对齐不可靠时会发生语义漂移，难以保证"生成词汇不超纲""文化断言可在知识库中找到支持"。因此，本文未采用端到端向量检索，而是构建**四层结构化知识图谱**（文化语用 / 跨文化维度 / HSK 语言体系 / 学习者认知），以复合主键 $(knowledge\_point\_id, hsk\_level, scene\_id)$ 精确匹配 + Neo4j 图遍历语义扩展的方式，将结构化知识以"硬约束"形式注入 prompt（`<graph_cultural_context>` 等块），从知识供给层面限定 LLM 的生成空间。这是对 GraphRAG"图增强生成"范式在垂直教育领域的实例化与强化。

## 2.4 跨文化二语习得与语用偏误分析

### 2.4.1 语用能力与文化真实性

跨文化二语习得的核心难点在于**语用能力**（pragmatic competence）：不仅"说得对"，还要"说得得体"。Hymes（1972）的"交际能力"框架与 Thomas（1983）对"语用语言失误 / 社会语用失误"的区分，奠定了跨文化语用偏误分析的理论基础。Godwin-Jones（2024）在此基础上尖锐指出：生成式 AI 在语用语言层面（可复现礼貌套语等模式）表现尚可，但在社会语用层面（依对话者关系、场景、情感权重动态调适）严重不足，其"恰当性"常是表层模拟。更关键的是训练语料的 WEIRD 偏向，使 LLM 生成非西方语境内容时易出现文化错配甚至刻板印象。

### 2.4.2 跨文化语言学习中的 LLM 局限

一项 2025 年发表于 *Humanities and Social Sciences Communications* 的研究系统归纳了 LLM 在跨文化语言学习中的三类局限：① 生成机制缺乏可控性，可能产出与文化事实冲突的内容（如混淆东亚各社会鞠躬礼含义）；② 百亿参数模型的推理延迟阻碍实时交互；③ 难以捕捉细粒度文化差异（如英美直接提问 vs 日韩间接暗示的谈判策略）。该研究主张以可控、确定性更强的模型（如 BERT）结合信念—计划逻辑保障文化准确性——其"确定性 vs 随机性"的权衡，与本文以 A1 纯算法画像 + 结构化 KG 约束 + A5 门控降低 LLM 随机风险的思路异曲同工。

### 2.4.3 母语驱动的差异化内容

Wang（2024）对西语母语者的研究提示：LLM 的交际相关性高度依赖"是否针对学习者母语背景定制"。本文由此提炼出"母语驱动的跨文化对比"（A3 CulturalComparator）范式——固定同一知识点（如"合餐制 / 餐桌礼仪"），依据学习者母语文化圈调用对应的跨文化维度数据，生成差异化、可感知的文化对比内容。这既是对"跨文化对比教学法"的算法化落地，也回应了 RQ3"不同母语文化圈是否存在系统性差异"的实证需求。

## 2.5 学习者建模与自适应干预

学习者建模是自适应学习的技术基石。传统方法依赖知识追踪（Knowledge Tracing, KT）与认知诊断，基于测验结果动态估计概念掌握度（Chu et al., 2025）。LLM Agent 框架则进一步引入长期学生画像记忆（习惯、偏好）与短期交互上下文，以维持教学连续性，并实现"依据情感状态（如受挫时给予鼓励）自适应调节"的可解释个性化。

本文的 A1 学习者画像分析器即在此脉络下设计，但有两点关键区别：① **纯算法、不调用 LLM**，以文化焦虑度 $A\in[0,100]$ 为核心动态变量，通过增量公式与离散化映射建立"情感状态 → 母语占比参数"的确定性传导链路，避免 LLM 随机性对画像稳定性的干扰；② 采用 EWMA 能力向量（$\alpha=0.7$）与三层持久化架构实现画像的渐进收敛更新。这一设计使系统的自适应既"有记忆"，又"可解释、可复现"，契合教育场景对可信性的要求。

## 2.6 本章小结与研究定位

表 2.1 将本文工作与上述相关研究进行定位对照。

| 研究方向 | 代表性工作 | 主要贡献 | 本文的区别与衔接 |
|----------|-----------|----------|------------------|
| LLM 教育内容生成 | Wang (2024); Chu et al. (2025) | 验证 LLM 辅助语言学习的潜力，指出单体短板 | 不止于"用 LLM"，而是以架构约束其可控性 |
| 教育多智能体 | 顾小清、郝祥军 (2025); Sun & Tai (2025); MultiTutor | 验证多智能体分工优于单智能体 | 锚定跨文化中文垂直领域 + KG/网关强化 |
| 知识增强生成 | Edge et al. (2024); Peng et al. (2024) | GraphRAG 三阶段范式 | 以四层结构化 KG "硬约束"替代跨语言向量检索 |
| 跨文化语用 | Godwin-Jones (2024); HSSC (2025); Thomas (1983) | 揭示 LLM 文化偏见与语用局限 | 以母语驱动对比 + 双模型仲裁对冲偏见 |
| 学习者建模 | Chu et al. (2025); KT 系列 | 长期画像 + 自适应 | 纯算法画像 + 确定性情感—语言映射 |

**研究定位**：本文处于"多智能体系统 × 知识图谱增强 × 跨文化二语习得"三者交汇处，核心创新不在于提出孤立的某一技术，而在于将三者**工程化地缝合为一个可控、可评测、可复现的跨文化中文教学内容生成框架**，并以消融实验为每一组件提供实证支撑。这一定位恰好弥补了现有文献中"多智能体教育研究偏重通用框架、跨文化语用研究偏重批判性分析、知识增强研究偏重开放域问答"三者相互脱节的不足。
