# 中文CCL论文推荐章节结构

## 论文元信息

- **目标会议/期刊**：CCL（中国计算语言学大会）或《中文信息学报》
- **语言**：中文
- **页数限制**：CCL长文一般8-10页（双栏）
- **参考文献**：30-50篇
- **投稿时需准备**：论文PDF + 匿名要求（去除作者信息）

---

## 推荐论文结构

### 摘要（约300字）

**结构**：背景 → 问题 → 方法 → 关键创新 → 实验概述 → 结论

**推荐内容**：

```
[背景] 大语言模型在对外汉语教学内容生成中面临文化幻觉和个性化不足两大挑战。
[问题] 现有方法依赖单一模型生成，缺乏结构化的文化知识约束和学习者状态自适应能力。
[方法] 本文提出...（使用 abstract_innovation.md 版本B）
[实验] 消融实验和人工评测表明...（概述核心数据）
[结论] 该框架为跨文化TCSL内容生成提供了...
```

**素材来源**：`08_method_drafts/abstract_innovation.md`

### 1. 引言（约1.5页）

**结构**：大背景 → 具体问题 → 现有方法不足 → 本文方法 → 贡献列表

#### §1.1 研究背景（3-4段）

- 第1段：对外汉语教学（TCSL）的全球化需求与个性化教学的矛盾
- 第2段：大语言模型在教育内容生成中的应用现状
- 第3段：跨文化TCSL场景的特殊挑战——文化幻觉、语用偏差、个性化缺失
- 第4段：概述本文的解决思路（一句话）

#### §1.2 问题定义（1-2段）

明确研究问题：
- RQ1：如何在多Agent生成管线中防止文化幻觉的级联传播？
- RQ2：如何在不依赖跨语言embedding的前提下实现精确的文化知识检索？
- RQ3：如何基于学习者情感状态实现教学内容的动态自适应？

#### §1.3 本文贡献（列表）

6项贡献精炼为3-4项（合并相关项）：
1. 内联门控的多Agent协同框架 + 三层Grounding校验
2. 结构化精确检索替代向量语义检索的知识增强机制
3. 文化焦虑度驱动的动态自适应与七维画像模型
4. （可选）面向中文语用准确性的多层保障机制

**素材来源**：`08_method_drafts/contribution_draft.md`

### 2. 相关工作（约1.5页）

**结构**：按主题分节，每节综述+定位本文差异

#### §2.1 教育领域的多智能体系统

- 智能教学系统（ITS）中的Agent角色分工
- AutoGen/CrewAI/LangGraph等多Agent框架在教育中的应用
- **本文定位**：提出内联门控范式，将质量校验嵌入Agent间传递路径

#### §2.2 检索增强生成（RAG）

- 标准向量RAG：Lewis et al. (2020), REALM, Atlas
- 教育领域的知识增强生成
- 跨语言RAG的挑战
- **本文定位**：以结构化精确检索替代向量检索，规避跨语言语义漂移

#### §2.3 学习者建模与自适应学习

- BKT (Corbett & Anderson, 1995)、DKT (Piech et al., 2015)
- 情感计算与焦虑度建模 (Horwitz et al., 1986 — Foreign Language Classroom Anxiety Scale)
- 自适应学习系统综述
- **本文定位**：将文化焦虑度作为内容生成的核心控制变量而非附属标签

#### §2.4 LLM幻觉缓解

- 幻觉检测：FActScore, SelfCheckGPT, SAFE
- 幻觉缓解策略：RAG grounding, constrained decoding, fact verification
- NLI-based faithfulness evaluation
- **本文定位**：以跨模型NLI裁判替代embedding相似度，实现可解释的文化Grounding

```

    ↓
第2阶段（5天）：填充表格 + 生成数据图 + 撰写实验章节
    ↓
第3阶段（5天）：文献调研 + 撰写相关工作
    ↓
第4阶段（3天）：撰写引言 + 讨论 + 结论
    ↓
第5阶段（2天）：整合方法章节（从已有Method草稿裁剪拼接）
    ↓

    ↓
第7阶段（1天）：最终校对 + 匿名化 + 提交
```

## 关键写作原则

1. **避免工程语言**：不出现"函数名""变量名""SQL语句"等代码级术语，替换为伪代码或数学符号
2. **突出方法创新而非系统实现**：读者关心"为什么这样设计"而非"代码怎么写"
3. **每个设计选择需有动机**：为什么用结构化检索而非向量检索？为什么α=0.7？
4. **图表自解释**：每张图表需能独立理解，不依赖正文
5. **实验与声明对应**：引言中的每项贡献需有对应的实验验证
6. **局限性诚实**：主动指出局限性比被审稿人指出更好
