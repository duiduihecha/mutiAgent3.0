## 三、招募文案（双语，可直接发群）

见同目录 `招募文案.md`，含中文版 + English 版，复制即可发北语留学生微信群 / 语伴群 / 朋友圈。

**招募要点**：
- 目标人数：3–6 人
- 覆盖多样性：**至少 3 种不同母语**（如英语 / 俄语 / 阿拉伯语 / 日语 / 韩语）+ **不同 HSK 等级**（HSK2–HSK5 各来一两个）
- 每人耗时：约 20–30 分钟（走流程 10–15 分钟 + 填反馈 5–10 分钟）
- 报酬：小额酬谢或奶茶/咖啡（你定，保持简单）

## 四、测试任务卡（留学生走流程时用）

让每位测试者**任选 1–2 个场景**完成任务（不是全做），覆盖不同母语/等级即可：

| 编号 | 场景 | 适合等级 | 看点 |
|------|------|----------|------|
| T1 | 问路指路（交通） | HSK2–3 | A2 母语讲解是否清楚、A3 文化对比（如"中国路名习惯"） |
| T2 | 急诊就医 | HSK4–5 | 专业词母语解释准确性、焦虑学习者是否被安抚 |
| T3 | 商场购物砍价 | HSK3–4 | 文化对比（砍价文化）、练习是否实用 |
| T4 | 节日习俗（春节/中秋） | HSK3–5 | 文化对比深度、有无冒犯/误解 |
| T5 | 点餐/请客 | HSK2–4 | 母语解释、社交语用是否地道 |

**走流程步骤**（让他们照做）：
1. 打开 `/learning`，填写/选择：母语、HSK 等级、学习动机、文化焦虑度
2. 输入一个知识点（如"问路"），点开始学习
3. 等待系统生成：母语讲解(A2) + 文化对比(A3) + 练习题(A4)
4. 通读生成内容，留意：哪里看不懂？哪里觉得不对/不舒服？哪里最喜欢？
5. 打开 `/feedback`，凭真实感受填写（评分 + 自由文字）

## 五、体验反馈维度（已内置到 /feedback 表单）

7 个评分维度（1–5，5 最好）+ 4 个自由文字，与系统组件**一一对应**，便于定位缺陷：

| 维度 | 对应系统组件 | 用来发现什么 |
|------|--------------|--------------|
| 易用性 | 整体 UI/流程 | 界面卡不卡、步骤懂不懂 |
| 母语讲解清楚度 | A2 母语阐释器 | 用母语解释中文是否真懂 |
| 文化对比有用性 | A3 文化对比器 | 对比是否真有帮助 |
| 文化对比准确性/冒犯 | A3 | **有没有错误/冒犯/文化误解**（高危项） |
| 练习题质量/难度 | A4 出题 | 题是否合适、超纲否 |
| 内容准确性 | 全链路 | **有没有胡说/幻觉**（高危项） |
| 整体满意度 | — | 综合 |

自由文字 4 项：最喜欢 / 卡住的地方 / 觉得不对或冒犯的内容 / 改进建议。

> 高危项（内容准确性、文化冒犯）是导师和审稿人最在意的，留学生若反馈"这里写错了/这让我不舒服"，优先级最高。

## 六、反馈收集与分析闭环（CEO 迭代）

1. 留学生提交 → 落盘 `data/feedback.jsonl`（每条一条 JSON，append-only，已 gitignore）
2. 你跑 `python3 scripts/aggregate_feedback.py` → 输出各维度平均分、自由文字汇总、按母语/HSK 分组
3. CEO 读汇总 → 归类缺陷 → 提 issue → 修代码（闭环到 P-04~P-16 等系统缺陷）
4. 修完 → 再测一轮 → 对比分数是否提升
