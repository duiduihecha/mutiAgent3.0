## 🇨🇳 中文版（发留学生中文群 / 朋友圈）

**【招募】免费体验一款中文学习 AI，帮我们提建议就有小礼物🎁**

大家好！我是北语的研究生，正在做一个**面向外国人的智能中文学习系统**（毕设项目）。
它可以用你的母语给你讲解中文知识点，还会对比"中国 vs 你家乡"的文化差异，并出练习题。

现在想找 **3–6 位外国留学生朋友**当首批体验官，走一遍系统、凭真实感受提建议。
你的母语和真实反馈，对这个系统能不能做好非常关键。

📋 参与方式：
- 约 20–30 分钟，在你方便的地方（线上共享屏幕或线下都行）
- 走完一次学习流程，再花几分钟填一份体验反馈（中英都可填）
- 完成后有小礼物/奶茶答谢 ☕

🌟 特别欢迎：母语是 **英语 / 俄语 / 阿拉伯语 / 日语 / 韩语** 等、HSK 2–5 级的同学。
不同母语和水平我们都需要，越多样越好！

感兴趣的同学私信我，或加我微信：______（填你的联系方式）
谢谢支持！🙏
