# 实验一进展汇报：多智能体架构消融实验

> 日期：2026-07-01
> 用途：明天组会汇报

---

## 一、我们在做什么实验

**核心问题**：我做的 5 个 AI Agent 分工协作（A1画像→A2阐释+A3对比→A4出题→A5质检），到底比"一个 LLM 干所有事"好多少？每个 Agent 各自贡献了什么？

**这是一个消融实验（Ablation Study）**——逐个关掉 Agent，观察质量变化。

---

## 二、实验怎么设计的

### 2.1 五个条件

同一个学习任务，跑 5 种不同的流水线：

| 条件 | 流水线 | 什么意思 |
|------|--------|---------|
| **C1 完整系统** | A1→A2+A3→A4→A5+KG | 所有 Agent 都在，有知识图谱数据 |
| **C2 单体LLM** | 一个 prompt 让 LLM 直接干所有事 | 没有 Agent 分工，没有 KG |
| **C3 去掉文化对比** | A1→A2→A4→A5+KG | 关掉 A3，看看少了文化对比会怎样 |
| **C4 去掉质量管控** | A1→A2+A3→A4+KG | 关掉 A5，A4 的原始输出直接当结果 |
| **C5 去掉阐释和对比** | A1→A4→A5+KG | 关掉 A2 和 A3，只留出题和质检 |

### 2.2 测试数据

从知识图谱里取 14 个学习场景（餐饮/校园/医疗/银行...），覆盖 4 种母语（英/日/韩/阿）× 2 个等级（初级HSK1 + 高级HSK7）：

```
14 场景 × 4 母语 × 2 等级 × 5 条件 = 560 次 LLM 调用
```

### 2.3 测什么

8 个自动指标 + AI 双裁判盲评（5 个维度）：

| 维度 | 测什么 |
|------|--------|
| 格式正确率 | JSON 能不能正常解析 |
| HSK 词表覆盖率 | 练习题用的中文词在不在官方 HSK 词表里 |
| KG 事实一致性 | 生成内容跟知识图谱里的知识点定义是否一致 |
| 偏见度 | 有没有文化刻板印象 |
| 题型丰富度 | 是只有选择题还是多题型混合 |
| 答案可判率 | 选择题的正确答案是不是唯一的 |
| AI 裁判评分 | 准确性、文化适切性、教学有效性、个体适配性、整体质量 |
| 生成耗时 | 多 Agent 到底慢多少 |

## 四、上周小规模试跑已经看到的结果

上周用 14 个场景 × 1 种母语(英语) × 1 个等级(HSK4) 小规模试跑了一次（70 次调用），已经有了一些初步发现：

| 指标 | C1完整系统 | C2单体LLM | 说明 |
|------|-----------|----------|------|
| **答案可判率** | 100% | **68.6%** | 单体 LLM 有 31% 的题答案格式不规范 |
| **题型种类** | 3.0 种 | **1.8 种** | 多 Agent 出的题题型更丰富 |
| **偏见拦截** | 0 例 | — | C4(无质检)出现了 1 例偏见，C1 被 A5 拦住了 |
| **生成耗时** | 50.5s | 8.5s | 多 Agent 慢 6 倍，但质量显著更好 |

**初步结论**：多 Agent 分工确实优于单体 LLM——主要表现在答案规范性和题型丰富度上。A5 质量管控有实际的偏见拦截价值。

## 五、这次实验比上次强在哪

| | 上周 | 这次 |
|---|------|------|
| 母语 | 只有英语 | 英/日/韩/阿 4 种 |
| HSK等级 | 只有 HSK4 | HSK1 + HSK7（初级/高级两极） |
| 每条条件的样本 | 14 条 | 112 条 |
| 总 LLM 调用 | 70 次 | 560 次 |
| 能回答的问题 | "多Agent比单体好吗" | **"对不同母语文化圈效果一样吗"** |

这次的关键变化是加入了**跨母语对比**——日语和阿拉伯语的学习者，系统生成的内容质量一样吗？——这是论文最核心的贡献点。
