|------|-------|-------|-------|-------|----------|

| C2 单体LLM | 1.77±0.97 | 4.88±0.32 | 3.19±0.88 | 3.00±0.00 | 12.60±2.00 |

**发现 (T47 配对 t 检验, n=26, C1 为基线)**:
- 总分 C1(15.80) vs C2(12.60) = **+3.20 分**, p<0.0001 显著 → 多Agent 显著优于单体
- 总分 C1 vs C3(12.94) = +2.86, p<0.0001 显著；C1 vs C5(13.03) = +2.77, p<0.0001 显著
- **A维度是拉开差距的主战场**: C1/C4 的 A=4.04 ≫ C2/C3/C5 的 1.7 左右(p<0.0001)；B/C/D 三维度各条件无显著差异

- C3(去A3) ≈ C5(去A2A3): 说明 A3(跨文化对比) 是提分主力，A2(母语阐释) 在 CIEval 上增量有限

**T45 内容一致性 (统计版, 同源对照法)**:
- C1 vs C4 内容相似度 0.4114 [0.391, 0.432]
- 同条件两次运行 C1 vs C1_r2 噪声地板 0.4109 [0.394, 0.428]
- 差值 -0.0006 [-0.024, +0.023] 跨 0 → **PASS**：A5 未引入额外改写（统计一致）

## 论文可用的核心论据

1. **多Agent > 单体**: 消融 C1(15.80) vs C2(12.60) = +3.20 分（p<0.0001），且差距几乎全部来自 A理论维度（C1=4.04 vs C2=1.77）
2. **A3(跨文化对比) 是提分主力**: C3(去A3)=12.94 ≈ C5(去A2A3)=13.03，说明去掉 A3 后性能退化与同时去掉 A2+A3 几乎相同 → A2 增量有限、A3 是核心
3. **A5 是纯质量网关**: C4(去A5)=15.65 与 C1 几乎无差（总分差 -0.15, p=0.405；T45 内容相似度与同条件噪声地板无差）→ A5 不改写内容
4. **CIEval 能区分模型/架构**: 单体 A=1.77 远低于多Agent A=4.04，且 B/C/D 维度各条件无显著差异，说明 CIEval 的区分力集中在"理论正确性"而非安全/空间/教学
5. **B安全维度全场封顶(~4.9)**: 所有条件都接近满分，说明安全护栏已默认生效，不再是区分条件

## T50: A5 质量网关独立实验（2026-08-07）

> 复用生产级 `GuardrailService.verifyA5JointArbitration` 对 RQ1 已生成内容重打分（C1_Full 26 + C2_NoAgent_Monolith 26 = 52 条）。A5 当前仲裁策略：DeepSeek 权威 + MiniMax advisory；本次 MiniMax 不可用走 DS 单模型降级（即生产现状）。
> 阈值修正：缓存准入 `CACHE_WRITE_CONFIDENCE_THRESHOLD = 0.85`（非旧文档写的 0.60）。

**T50a 拒绝率 + 判别力**
- 拒绝率：**C1(多Agent) = 0.0%** vs **C2(单体) = 23.1%** → A5 对好内容零误杀、对弱内容拦截约 1/4，与 T45/T47「A5 纯质量网关」一致。
- A5 confidence 均值：**C1 = 0.843** 显著 > **C2 = 0.665**（t=5.74, p≈2e-6）→ A5 在置信度层面即区分多Agent 与单体。
- 校准：同条件内 A5 confidence 与 CIEval 总分弱相关（|Pearson r|<0.15），属正常——A5 评练习题质量（拼音/干扰项/文化合规/等级适配），CIEval 评教学多维，不同构念；判别力在**跨架构层面**而非逐条对齐。

**T50b 缓存准入率 + 命中率模拟**
- 缓存准入率（conf≥0.85）：**C1 = 73.1%** vs **C2 = 15.4%** → 多Agent 内容可准入率约为单体的 **4.7 倍**，同等流量下单体需多再生约 **3.1 倍** → A5 门控带来显著成本优势。
- 门控不降解好内容：C1 门控池 vs 全量池 served CIEval = 15.67 vs 15.80（几乎无差）。
