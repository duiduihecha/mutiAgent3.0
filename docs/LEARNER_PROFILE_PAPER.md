# 3. 学习者画像与自适应干预系统

## 摘要

本节提出一种面向跨文化第二语言学习的学习者画像系统。系统采用"四层记忆+双闭环"架构：底层以关系型数据库与图数据库分别存储时序行为数据与认知拓扑；上层以规则引擎驱动情感检测、能力评估与知识追踪，在无需大语言模型参与的条件下实现实时画像更新与个性化干预。系统在"母语驱动中文学习"场景中部署，支持八种母语文化圈的跨文化自适应内容分发与学习路径推荐。

---

## 3.1 四层记忆架构

学习者状态管理遵循"原始数据→聚合快照→长期画像→认知图谱"的分层原则，自底向上分为四层（L1–L4），如图1所示。

**L1 学习记录层 (learning_records)** 存储每一次答题的原始数据，包含逐题正确与否、用户作答内容、答题耗时及所属知识点标识。该层以结构化 JSONB 字段 `practice_result` 保存完整的练习轨迹，为上层聚合提供不可变的数据基底。

**L2 评估快照层 (assessment_records)** 对单轮学习进行聚合评估。每条记录包含本轮的能力向量快照（前/后）、焦虑度（前/后）、各维度正确率、错误模式列表、贝叶斯知识追踪更新后的掌握概率以及情感检测结果。该层是连接原始行为与长期画像的中枢。

**L3 学习者画像层 (learners)** 维护学习者的当前状态行。字段包括：母语（决定文化圈归属）、HSK 等级、学习动机（tourism / study_abroad / work / interest / exam）、文化焦虑度（0–100）、五维能力向量 [语法, 听力, 口语, 文化语用, 阅读]（各维 0–100）及累计学习轮次。L3 还通过触发规则向 `learner_profile_snapshots` 表写入历史快照——触发条件按优先级依次为：首次学习、HSK 等级变化、焦虑度变化 ≥10、任一能力维度变化 ≥15、或每 10 轮周期写入。

**L4 认知图谱层 (Neo4j)** 以属性图建模学习者与知识体系的关系。图模式包含三类节点——`Learner`（学习者）、`KnowledgePoint`（知识点）、`CulturalDimension`（文化维度）——以及三类边：`BELONGS_TO`（学习者→文化圈归属）、`MASTERED`（学习者→知识点，带权重的掌握度边）、`PREREQUISITE`（知识点→知识点，规则引擎构建的 152 条学习前置边）。

```
L1 learning_records  →  L2 assessment_records  →  L3 learners/snapshots  →  L4 Neo4j Graph
    原始答题数据              聚合评估快照                 长期画像状态                认知图谱
```

四层之间通过 `results pipeline` 串行写入（STEP 1→2→3→3.5→4），保证数据一致性的同时，L4 写入失败不阻塞 L1–L3 的主流程。

## 3.2 情感检测引擎

情感检测模块（`emotion-check.ts`）是一个零大语言模型调用的规则引擎。每轮学习结束后，系统采集六项底层信号，通过阈值判定将学习者情感状态分类为三级（green / yellow / red），并生成对应干预动作。

### 3.2.1 信号定义与计算

| 信号 | 计算方式 | 触发阈值 (Yellow) | 触发阈值 (Red) |
|---|---|---|---|
| 挫败感 (frustration) | 尾部连续错误数 / 总题数，clamp 至 [0,1] | 连续 ≥3 题 | 连续 ≥5 题 |
| 疲劳 (fatigue) | 焦虑↑ ∧ 正确率≤0.5 ∧ 会话≥20min → 1.0 | — | 三者同时满足 |
| 脱离 (disengagement) | 全会话最长连续正确数≥8 ∧ 正确率>0.9 → 取 min(1, streak/N) | ≥8 题 | — |
| 焦虑突增 (anxiety_spike) | Δanxiety = anxietyAfter − anxietyBefore | Δ ≥ 15 | Δ ≥ 25 |
| 同类错误 (repeated_same_error) | 同一维度答错次数（跨题目聚合） | ≥2 次 | ≥3 次 |
| 正确率趋势 (accuracy_trend) | correctRate < 0.4 → declining; > 0.8 → improving; 其余 stable | — | — |

其中挫败感采用尾部扫描（从数组末尾向前计数直到遇到正确），反映最近的挫败状态；脱离检测则采用全数组最长连续正确数扫描（非仅尾部），防止末尾偶发错误掩蔽前期的"过于简单"信号——此为系统在实测中发现并修复的边界 bug。

### 3.2.2 状态判定与干预

采用"Red 优先"的级联判定逻辑：任一 red 信号触发则整体状态为 red；否则任一 yellow 信号触发则为 yellow；其余为 green。

干预动作按状态与主导信号分配：

- **Red + 疲劳** → `suggest_break`：提示休息建议，不调整难度。
- **Red + 挫败/同类错误** → `lower_difficulty`：降低内容难度系数至 0.7，强化基础。
- **Red + 其他** → `encourage`：鼓励性反馈。
- **Yellow + 脱离** → `raise_difficulty`：提升难度系数至 1.2，增大挑战。
- **Yellow + 其他** → `encourage`：温和提示。

此外，red 状态额外对焦虑度施加 +10 的惩罚偏移，使系统对重度负面情感产生更保守的内容策略。

### 3.2.3 跨文化干预话术

干预提示语按学习者母语文化圈定制，当前支持英语圈（hc_en）、日语圈（hc_ja）、韩语圈（hc_ko）、西班牙语圈（hc_es）、法语圈（hc_fr）及中文兜底。每种干预动作（鼓励 / 降难度 / 建议休息 / 升难度）均有独立的话术集合，系统按 `homeCultureCode` 匹配对应语言，未覆盖的文化圈自动回退至中文。

## 3.3 焦虑度追踪

焦虑度更新采用对称线性公式。令当前轮正确率为 $r \in [0, 1]$，焦虑变化量为：

$$\Delta a = (0.5 - r) \times 20$$

$$a_{t+1} = \text{clamp}(a_t + \Delta a,\ 0,\ 100)$$

该公式以 50% 正确率为锚点：全对时焦虑降低 10 分，全错时焦虑上升 10 分，50% 正确率时保持不变。焦虑变化值与正确率呈严格线性关系，确保了模型的可解释性。

焦虑度进一步映射为三级离散标签——low (<40)、medium [40,80]、high (>80)——用于驱动 A2 母语阐释智能体的母语占比参数：高焦虑 75%、中焦虑 50%、低焦虑 25%。

## 3.4 能力向量估计

五维能力向量 $v = [v_1, v_2, v_3, v_4, v_5]$ 分别对应语法、听力、口语、文化语用和阅读能力。每轮更新采用指数加权移动平均（EWMA），平滑系数 $\alpha = 0.7$：

$$v_i^{(t+1)} = \text{round}\left(\alpha \cdot s_i + (1 - \alpha) \cdot v_i^{(t)}\right)$$

其中 $s_i$ 为维度 $i$ 在本轮的加权正确率（$\sum (正确? 100:0 \times w_j) / \sum w_j$）。未涉及的维度保持不变。所有值 clamp 至 [0, 100]。

高 $\alpha$ 值使向量对近期表现高度敏感——单轮好/差表现即可显著拉动对应维度。此设计优先于响应速度而非平滑性，适配学习场景中对学习者状态变化的快速感知需求。

## 3.5 贝叶斯知识追踪

系统按知识点粒度运行贝叶斯知识追踪（BKT）以估计每个 learner–knowledge point 对的掌握概率。采用标准两状态隐马尔可夫模型，三个全局参数：

| 参数 | 含义 | 值 |
|---|---|---|
| $P(L_0)$ | 初始掌握概率 | 0.2 |
| $P(G)$ | 未掌握时猜对的概率 (guess) | 0.25 |
| $P(S)$ | 已掌握时失误的概率 (slip) | 0.10 |

当观察到正确作答时，后验掌握概率为：

$$P(L \mid \text{correct}) = \frac{(1 - P(S)) \cdot P(L)}{(1 - P(S)) \cdot P(L) + P(G) \cdot (1 - P(L))}$$

当观察到错误作答时：

$$P(L \mid \text{wrong}) = \frac{P(S) \cdot P(L)}{P(S) \cdot P(L) + (1 - P(G)) \cdot (1 - P(L))}$$

每次学习前，系统从 assessment_records 中读取同一知识点最近一次 BKT 后验概率作为本轮先验；无历史记录时使用默认先验 0.2。BKT 更新后的掌握概率同时写入 L2 评估记录和 L4 Neo4j 的 MASTERED 边权重，驱动推荐引擎的解锁判断。

## 3.6 学习路径推荐引擎

### 3.6.1 前置关系构建

知识点之间的 `PREREQUISITE` 边由规则引擎自动构建（`buildPrerequisiteEdges()`），无需人工标注或大语言模型推断。算法为：每个 Scene 内按 HSK 等级升序排列 KnowledgePoint，串链 KP₀ → KP₁ → KP₂；同一 Domain 内，前一 Scene 末尾 KP 桥接至下一 Scene 首个 KP。构建过程使用 Cypher `MERGE` 保证幂等性，当前生成 152 条学习路径边。

### 3.6.2 五因子加权评分

推荐引擎 `getRecommendations(learnerId, limit)` 为每个候选知识点计算加权总分（0–1）：

$$S = 0.20 \cdot M + 0.25 \cdot H + 0.25 \cdot U + 0.15 \cdot W + 0.15 \cdot N$$

其中各因子定义如下：

| 因子 | 权重 | 含义 | 计算 |
|---|---|---|---|
| $M$ 动机匹配 | 0.20 | KP 所在 domain 是否匹配学习动机 | 匹配→1.0；不匹配→0.3；interest/exam→恒 1.0 |
| $H$ HSK 邻近度 | 0.25 | KP 等级与学习者等级的距离 | $1 - \vert hsk_{kp} - hsk_{learner} \vert / 9$ |
| $U$ 解锁状态 | 0.25 | 所有前置 KP 是否已掌握 | 全部 mastery ≥ 0.8 → 1.0；否则 0 |
| $W$ 弱项维度 | 0.15 | KP 是否涉及学习者弱项 | 匹配→1.0；不匹配→0；"综合能力"弱项→0.5 |
| $N$ 新颖度 | 0.15 | KP 是否尚未掌握 | mastery < 0.6 → 1.0；已掌握→0 |

### 3.6.3 排序策略

排序采用两级键：主键为 `is_unlocked`（已解锁优先），次键为加权总分（降序）。此设计确保解锁状态对排序产生刚性约束——一个未解锁知识点无论其他因子得分多高，都不会排在已解锁知识点之前。冷启动场景下（无 mastery 数据），排序策略调整为主键 motivation 得分、次键 HSK 等升序，使入门级且动机匹配的内容优先曝光。

## 3.7 冷启动与语言切换

新建学习者时，ability_vector 初始化为各维 50、cultural_anxiety_score 初始化为 50。前后无 mastery 数据，推荐引擎回退至冷启动策略。当学习者切换母语文化圈时，系统执行三重重置：(1) ability_vector 恢复默认值，(2) cultural_anxiety_score 恢复默认值，(3) Neo4j 中该 learner 的所有 MASTERED 边被清除。此设计基于以下假设：不同母语背景的学习者面对相同的目标语言时，其学习画像应有独立起点，母语迁移效应的差异使得跨文化圈的掌握度数据不可直接复用。

## 3.8 与多智能体系统的接口

学习者画像系统通过以下接口向 A1–A5 多智能体管线提供状态数据：

- **A1 (LearnerProfiler)** 读取 L3 当前画像与 L2 短期趋势，执行纯规则分析（不调大语言模型），输出弱项维度列表、正确率趋势、重复错误模式及建议的母语占比。
- **A2–A4** 接收焦虑等级与母语占比参数，自适应调整内容生成的母语辅助比例。
- **推荐引擎** 独立于智能体管线运行，在首页和完成页供前端直接调用，为学习者提供"下一步学什么"的引导。

整体设计原则为：**L1 存数据、L2 做聚合、L3 管状态、L4 建图谱、推荐引擎驱动下一步**。情感检测、焦虑追踪、能力估计、知识追踪、路径推荐五个子系统全部闭环在 results pipeline 中，确保状态更新与学习行为严格同步。
