## 一、核心研究问题

### 主研究问题

> 多智能体协同架构结合结构化知识图谱，能否在跨文化中文学习场景中，**显著提升** LLM 生成内容的**教育质量**（准确性、文化适切性、个体适配性），并**有效抑制**幻觉与偏见？

### 四个子问题（各对应一章的实验）

| # | 子问题 | 核心关注点 | 对应实验 |
|---|--------|-----------|---------|
| **RQ1** | 多智能体**分工协作**是否优于单体 LLM？A1→A2+A3→A4→A5 的流水线架构，相比"一个 Agent 干所有事"，在内容质量上有多大提升？ | 架构有效性 | 消融实验 |
| **RQ2** | 知识图谱作为**结构化知识底座**，能否减少 LLM 在教育内容生成中的事实性错误（幻觉）和文化偏见？减少幅度有多大？ | 知识增强效果 | KG增强对比实验 |
| **RQ3** | **母语驱动的跨文化对比**（A3 CulturalComparator）是否真正提升了学习者的理解度和参与度？不同母语文化圈之间是否存在系统性差异？ | 跨文化适配 | 多母语圈用户实验 |
| **RQ4** | 多层**防幻觉网关**（回译校验+对抗盲测+硬规则+双模型仲裁）能否在实践中有效拦截不合格内容？各防线的贡献度如何？ | 质量保障机制 | 网关效能分析 |

## 三、四个实验的详细设计

### 3.1 实验一（RQ1）：多智能体架构消融实验

**目的**：验证 5-Agent 分工协作架构的必要性和有效性。

**实验条件**（5个变体）：

| 条件编号 | 条件名称 | Agent流水线 | 含义 |
|---------|---------|------------|------|
| C1 | **Full** | A1 → A2+A3 → A4 → A5 + KG | 完整系统 |
| C2 | **NoAgent（单体基线）** | 1个Agent做所有事 + KG | 单体LLM基线 |
| C3 | **NoA3** | A1 → A2 → A4 → A5 + KG | 去掉文化对比Agent |
| C4 | **NoA5** | A1 → A2+A3 → A4 + KG | 去掉质量管控Agent |
| C5 | **NoA2A3** | A1 → A4 → A5 + KG | 去掉阐释和对比，只做内容生成 |

**测试用例**：

- 从14个Domain中各选2个场景 = **28个场景**
- 4种母语（英语/日语/韩语/阿拉伯语） × 3个HSK等级（1/4/7） = **12种学习者配置**
- 总计：28 × 12 = **336个测试用例**
- 每个条件对同一输入各生成一次：336 × 5 = **1,680次生成**

**预期发现**：

| 比较 | 预期结果 |
|------|---------|
| C1 vs C2（Full vs 单体） | Full 在所有维度显著优于单体基线 |
| C1 vs C3（Full vs NoA3） | NoA3 在"文化适切性"维度下降最明显 |
| C1 vs C4（Full vs NoA5） | NoA5 在"格式正确率"和"偏见度"维度下降最明显 |
| C1 vs C5（Full vs NoA2A3） | NoA2A3 在"个体适配性"维度下降最明显 |

---

### 3.2 实验二（RQ2）：知识图谱增强效果实验

**目的**：量化知识图谱对LLM生成质量的提升幅度。

**实验条件**（3个变体）：

| 条件 | 描述 |
|------|------|
| **Full+KG** | A2/A3/A4 从 Neo4j 读取图谱数据（HAS_DIMENSION / MANIFESTED_IN / REQUIRES_VOCAB）注入 prompt |
| **NoKG** | A2/A3/A4 仅依赖 LLM 参数知识，不查询图谱（去掉 prompt 中的 `<graph_cultural_context>` 等块） |
| **RAG only** | 用向量检索 `rag_cache` 表替代图谱查询，对比结构化 KG vs 非结构化 RAG |

**测试用例**：同实验一，每个条件各生成一次，共 336 × 3 = **1,008次生成**。

**关键测量**：

| 指标 | 测量方法 | 预期 |
|------|---------|------|
| 事实一致性 | 生成内容中的文化事实断言能否在图谱中找到支持节点 | Full+KG >> NoKG |
| 词汇超纲率 | 生成练习题中超出目标HSK等级的词汇占比 | Full+KG 显著低于 NoKG |
| 文化维度准确性 | 生成内容中文化描述的 Hofstede/Hall 维度标注与图谱是否一致 | Full+KG >> NoKG |
| 知识覆盖率 | A2/A3 prompt 中实际使用的图谱字段数 / 可用的图谱字段数 | — |

### 3.3 实验三（RQ3）：跨文化适配效果评估

**目的**：验证母语驱动的文化对比（A3）能否真正做到差异化内容，且差异合理。

**实验方法**：

- 固定同一个知识点（如"合餐制 / 餐桌礼仪"），用**8种母语**各生成内容
- 比较 A3 生成的跨文化对比是否感知到真实的母语文化差异

**量化分析**：

| 分析维度 | 方法 |
|---------|------|
| A2 语言复杂度自适应 | 测量高焦虑（>80）vs 低焦虑（<40）时母语阐释的文本长度和可读性差异 |
| A3 文化维度调用准确性 | 检查 A3 是否正确调用了对应 HomeCulture 的 `MANIFESTED_IN` 数据 |
| A4 练习题差异化程度 | 不同母语的练习题是否在文化场景设定上有明显差异 |

**用户实验**：

- 招募8种母语背景的中文学习者各 3-5 人（共 **24-40人**）
- 每人阅读系统为自己母语生成的内容（2-3个场景）
- 7点李克特量表评价：
  - 理解容易度（Comprehensibility）
  - 文化准确度感知（Cultural Accuracy）
  - 学习兴趣激发度（Engagement）
  - 焦虑度变化（pre/post 自评）

---

### 3.4 实验四（RQ4）：防幻觉网关有效性验证

**目的**：验证4道防线的拦截效能和各自贡献度。

**数据来源**：实验一 C4（NoA5）条件下 A4 的原始输出（336条无质量管控的生成结果）作为待检测样本。

**逐防线测量**：

| 防线 | 测量指标 | 方法 |
|------|---------|------|
| 回译校验 | 拦截率 / 误拦率 | 回译后语义一致性 < 阈值 → 拦截；人工判定不合格但未被拦截 → 漏拦 |
| 对抗盲测 | 答案不一致率 | 解题模型给出的答案与 A4 标注答案是否一致 |
| 硬规则过滤 | HSK词汇覆盖率 / 拼音格式错误率 / JSON格式错误率 | 纯规则统计 |
| 双模型仲裁 | 双模型评分相关系数 / 双低分拦截率 | DeepSeek + MiniMax 交叉评分 |

**关键分析**：

- 单一防线拦截率（每条防线独立运行时的拦截比例）
- 组合防线拦截率（防线叠加后的拦截率提升幅度）
- 误拦率（拦截了本应通过的好内容——需要人工 gold standard 判定）
- **防线贡献度排序**：哪条防线贡献最大，哪条最容易被绕过

## 五、评估指标体系

### 5.1 自动化评估指标

| 维度 | 指标 | 测量方法 |
|------|------|---------|
| **格式规范性** | JSON格式正确率 | `safeJsonParse()` 成功率 |
| **HSK难度匹配** | 词汇超纲率 | 生成词汇的HSK等级 vs 目标等级，计算超出比例 |
| **事实准确性** | 图谱事实一致性 | 生成内容中的文化断言能否在 Neo4j 中找到支持节点 |
| **文化偏见度** | 偏见关键词命中率 | `detectBias()` 输出的 `biasScore` |
| **内容多样性** | 题型分布 / 词汇多样性 | 选择题vs判断题比例 / type-token ratio |
| **生成效率** | 端到端响应时间 | 各Agent耗时分解（A1纯算法 / A2+A3并行 / A4 / A5） |
| **练习题质量** | 答案可判别性 | 选择题正确选项的唯一性，判断题答案明确性 |

### 5.2 人工评估指标（专家评教）

招募 **3-5位** 国际中文教育专业的研究生或教师，对生成内容做5维评分（1-5分）。

先做一轮 **pilot**（10条样本）计算 **inter-rater reliability（Krippendorff's α）**，α < 0.7 则修订 rubric 后重做。

| 维度 | 描述 | 评分标准要点 |
|------|------|------------|
| **准确性** (Accuracy) | 文化描述是否准确，语言点解释是否无误 | 5=完全准确；3=有小错但不影响理解；1=严重错误 |
| **文化适切性** (Cultural Appropriateness) | 跨文化对比是否恰当，是否避免了刻板印象 | 5=精细对比有洞察；3=基本正确但泛泛；1=含刻板印象或偏见 |
| **教学有效性** (Pedagogical Effectiveness) | 练习题设计是否合理，是否能有效检测理解 | 5=题目有层次，能测到深层理解；3=题目基本可用；1=题目无效 |
| **个体适配性** (Personalization) | 内容难度是否匹配HSK等级，文化解释是否匹配母语背景 | 5=精准匹配；3=大致匹配；1=完全不匹配 |
| **整体质量** (Overall Quality) | 综合评价，是否可直接用于教学 | 5=可直接使用；3=需少量修改；1=不可用 |

### 5.3 学习者主观评估（实验三用）

| 维度 | 量表 | 题数 |
|------|------|------|
| 理解容易度 | 7点李克特（1=完全不懂，7=完全理解） | 3题 |
| 文化准确度感知 | 7点李克特（1=完全不准确，7=非常准确） | 3题 |
| 学习兴趣激发度 | 7点李克特（1=毫无兴趣，7=非常有兴趣） | 3题 |
| 焦虑度变化 | 单一问题 pre/post 自评（0-100） | 2题 |

| 招不到足够的学习者被试 | 中 | 高 | 实验三可降级为专家评估为主 + 小样本学习者做定性验证 |
| 消融实验的统计差异不显著 | 低 | 高 | 增大测试用例数（28场景→全56场景）；用 bootstrap 替代参数检验 |
| 专家评分者间一致性低 | 中 | 中 | pilot 轮调试 rubric；必要时增加评分者人数 |
| 导师认为论文范围太大 | 中 | 中 | 准备好精简版方案（只保留 RQ1+RQ2，去掉 RQ3） |

## 十、精简版方案（备选）

如果导师觉得4个RQ太多，可以精简为：

**保留 RQ1 + RQ2，去掉 RQ3 + RQ4**：

- RQ1（架构有效性）+ RQ2（KG增强效果）是两个最核心的实验
- RQ3（跨文化适配）降级为论文"讨论"章节的一个定性小节
- RQ4（防幻觉网关）降级为系统设计章节的一个技术描述，不单独做实验

精简版的工作量约减少40%，但仍能支撑一篇完整的硕士论文。

---

## 十一、与导师讨论要点

见导师前准备好以下问题的答案：

1. **论文题目**是否可以，是否需要调整关键词或范围
2. **4个子问题**是否合理，是否需要增减或调整
3. **实验设计**上是否有额外要求：
   - 是否需要 IRB 审批？（涉及人类被试的用户实验）
   - 被试人数是否有硬性要求？
   - 是否一定要做"和他人系统的对比"而非仅做消融？
4. **学科归属**：论文应投哪个学科方向？（教育技术 / 计算语言学 / AI应用 / 国际中文教育）
5. **论文篇幅要求**：硕士论文的字数/页数要求是多少
