# 导师汇报：多智能体跨文化阐释系统与消融实验

> 准备时长：10分钟 | 重点：理论框架 + 实验结果

---

## 一、研究问题（1分钟）

**核心问题**：LLM 为不同文化背景的学习者生成中文教学内容时，质量是否一致？知识图谱能否提升跨文化阐释的质量？

**具体做三件事**：
1. 构建了一个 5-Agent 协同的跨文化中文学习系统（A1画像→A2阐释+A3对比→A4出题→A5质检）
2. 定义一个评测基准 CIEval（Cross-cultural Interpretation Evaluation），评测"跨文化阐释好不好"
3. 通过消融实验量化每个 Agent 的贡献

---

## 二、系统做了什么（2分钟）

- **输入**：中国文化概念 + 学习者母语 + HSK等级
- **处理**：5 个 Agent 协同 + 知识图谱注入文化数据
- **输出**：母语文化阐释 + 跨文化对比 + 练习题

**理论基础**：李庆本"跨文化阐释"三维原则 → 操作化为 Agent 行为约束

---

## 三、怎么评测（2分钟）

**消融实验：20 个测试用例 × 5 种流水线 = 100 次生成**

| 条件 | 含义 |
|------|------|
| C1 完整系统 | 5个Agent都在 + 知识图谱 |
| C2 单体LLM | 一个 prompt 全部干完 |
| C3 去掉A3 | 缺文化对比 Agent |
| C4 去掉A5 | 缺质量审核 Agent |
| C5 去掉A2A3 | 缺阐释和对比 |

**用 CIEval 四维度打分（1-5分）**：
- **A 理论契合度**：有没有用 Hofstede/Hall 框架做文化对比
- **B 文化安全性**：有没有偏见、刻板印象
- **C 空间中介有效性**：母语阐释是否做得好
- **D 教学实用性**：练习题是否合理

**裁判**：校内 MiniMax 模型独立评测（不是生成模型 DeepSeek）

---

## 四、实验结果（3分钟）

### 表1：消融实验 CIEval 评分（n=20）

| 条件 | A理论 | B安全 | C空间 | D教学 | CIEval总分 |
|------|-------|-------|-------|-------|----------|
| **C1 完整系统** | **3.79** | 5.00 | 3.05 | 3.05 | **15.04** |
| C2 单体LLM | 1.50 | 5.00 | 2.55 | 2.90 | 11.67 |
| C3 去掉A3 | 1.85 | 5.00 | 3.15 | 3.00 | 12.77 |
| C4 去掉A5 | 4.10 | 5.00 | 3.00 | 3.00 | 15.32 |
| C5 去掉A2A3 | 1.60 | 5.00 | 2.10 | 3.00 | 11.42 |

### 核心发现

**发现1：A2+A3 是系统的核心价值来源**
- 去掉 A2+A3 后（C5），总分从 15.04 跌到 11.42（-24%）
- A 维度从 3.79 跌到 1.60——没有阐释和对比，LLM 只会做"中国X，外国Y"的浅层对比

**发现2：A3 单独去掉，A 维度暴跌**
- C3（无A3）的 A 维度只有 1.85——文化对比 Agent 对理论契合度贡献最大

**发现3：单体 LLM 完全不会做学术框架对比（A=1.50）**
- 没有知识图谱数据 + 没有分工 → LLM 的对比退化为泛泛而谈

**发现4：B 维度（文化安全性）全部满分**
- DeepSeek 生成内容本身安全性高，A5 的偏见拦截在此场景价值有限

### 案例对比

同一个场景"夜市点菜/英语/HSK5"：

> **C1（完整，A=5）**："根据 Hall 的高低语境理论，中国的间接点餐方式（'随便''看着办'）是高语境文化的典型表达..."
>
> **C2（单体，A=3）**："在夜市，你可以用'这个多少钱？'来询问价格..." —— 只有实操技巧，没有文化分析
