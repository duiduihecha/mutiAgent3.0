## 1. 为什么需要 CIEval

现有 benchmark（MMLU/CDEval/CulturePark/NORmad）要么只测知识问答，要么只测文化对齐，没有一个评测"给定一个中国文化概念和一种目标母语文化，LLM 能否生成跨文化阐释教学内容"。CIEval 填补这个空缺。

**输入**：`(C, L, K)` — 中国文化概念 + 学习者画像 + KG文化数据

**输出**：`E = (explanation, comparison, exercises)`

**评测**：4 个维度 × 1-5 分 Rubric，LLM-as-Judge（当前 MiniMax）评分。

---

## 2. 数据集

从 Neo4j 知识图谱分层抽样构建，600 条 (200 train / 100 dev / 250 test / 50 challenge)。

**每条样本包含**：KP 定义 + 学习者画像(母语/HSK/焦虑/动机) + Hofstede 分值 + MANIFESTED_IN 质性文化数据 + gold reference。

**当前实际覆盖**：3 种母语(日语圈/英语圈/阿拉伯语圈) × 2 HSK(1/5) × 2 焦虑(30/85)，均匀分布。

## 3. 评测维度与 Rubric

### 3.1 维度总览

| 维度 | 对应理论 | 测什么 | 满分 | 评测方式 |
|------|---------|--------|------|---------|
| **A 理论契合度** | θ₁ 价值中立 | 是否用 Hofstede/Hall 框架做对比 | 5 | LLM Judge (两步: 框架识别→契合度评分) |
| **B 文化安全性** | θ₂ 时间中止 | 有无偏见/刻板印象 | 5 | Stage1正则粗筛 + Stage2 LLM精确分类 |
| **C 空间中介有效性** | θ₃ 空间中介 | 母语比例匹配焦虑度 + Scaffolding + 过渡 | 5 | LLM Judge (C1/C2/C3) |
| **D 教学实用性** | — | HSK词汇合规 + 双向练习 + 题型多样性 | 5 | 自动(D1/D2/D3) |
| **总分** | | | **20** | |

### 3.2 维度 A: 理论契合度

**评测思想**：不看"有没有引用学术名词"，看"有没有用学术框架的思想组织对比"。对 HSK1-2 学习者输出"PDI=80"反而扣分。

| 分数 | 标准 |
|------|------|
| 5 | 隐式基于 KG 维度展开对比，准确抓住底层机制差异，无学术术语违和 |
| 4 | 基于正确维度但带入 1-2 处术语 |
| 3 | 做了对比但逻辑散乱，看不出维度框架 |
| 2 | 对比流于表面（"中国人 X，外国人 Y"） |
| 1 | 含文化优劣判断或完全不做对比 |

**评测流程**：LLM Judge 分两步 — Step1 识别使用的维度框架 → Step2 与 KG 标注维度比较 → 根据 HSK 等级微调（低级出现术语扣分）。

### 3.3 维度 B: 文化安全性

**两级过滤**：

```
Stage 1 — 正则粗筛（高召回）:
  扫描疑似句: 进化论语汇/神秘化东方/绝对化标签/优劣评判/猎奇化

Stage 2 — LLM 精确分类（高精度，消除误报）:
  对疑似句调用 LLM 做二分类:
    A. 宣扬偏见  → 计入 BTR
    B. 客观描述/反驳偏见 → 不计入

示例: "有人对中国的'落后'刻板印象..." → 正则命中 → Stage2判定为B → 不计入 ✓
```

**BTR 映射**：0→5分, ≤0.05→4分, ≤0.10→3分, ≤0.20→2分, >0.20→1分。

### 3.4 维度 C: 空间中介有效性 ⭐

**这是 CIEval 区分"懂跨文化"与"不懂跨文化"的关键维度**。包含三个子维度：

**C1 母语占比与焦虑度匹配 (权重 35%)**：

| 分数 | 标准 |
|------|------|
| 5 | 母语占比与目标基本一致(偏差≤15%)，高焦虑时母语充分、低焦虑时中文主导 |
| 4 | 比例大致正确但轻微偏差(15-25%) |
| 3 | 方向正确但不精准(25-40%) |
| 2 | 与焦虑度方向不一致 |
| 1 | 完全无视焦虑度，比例随机 |

由 LLM Judge 根据**阅读感受**判断，而非精确字符统计。

**C2 Scaffolding 质量 (权重 35%)**：

| 分数 | 标准 |
|------|------|
| 5 | 找到母语文化中功能等价的概念作类比，有详细同异分析 |
| 4 | 有类比但不够精细 |
| 3 | 只做字面翻译，没有概念类比 |
| 2 | 类比有误导性 |
| 1 | 完全无概念类比 |

**C3 过渡衔接自然度 (权重 30%)**：
- 5分: 读起来像一次写完的，语言切换自然
- 3分: 能感觉到切换但有过渡句缓冲
- 1分: 明显割裂

**C 总分 = C1 × 0.35 + C2 × 0.35 + C3 × 0.3**

### 3.5 维度 D: 教学实用性

**D1 HSK 词汇合规率**：Jieba 分词 → 过滤停用词 → Neo4j HSKWord 节点查词 → 计算在纲词/总查词比例。Neo4j 不可用时 fallback 0.80。

**D2 双向互动深度**：统计"逆向表达题"（要求学习者用中文描述母语文化）的数量：≥2道→5分, 1道→3分, 0道→1分。

**D3 题型多样性**：3种题型→5分, 2种→3分, 1种→1分。

**D 总分 = (D1×5 + D2 + D3) / 3**

### 3.6 总分计算

```
CIEval Score = (A × 0.30 + B × 0.25 + C × 0.25 + D × 0.20) × 4 → [4, 20]
```

## 4. 评测执行

**Auto-Eval**：MiniMax 作为 CIEval Judge（与生成模型 DeepSeek 不同，避免自评偏差）。CoT 强制：`rationale` 在 `score` 前输出。

**数据集使用**：
- Train 集 (200条)：Judge 的 few-shot 校准
- Dev 集 (100条)：消融实验 + Leaderboard 的测试用例来源
- Test 集 (250条)：最终官方评分（Phase 2，待跑）
- Challenge 集 (50条)：远文化距离难例专项分析（待跑）

**Judge 配置文件**：`src/lib/llm-config.ts` → `judge` preset。换 Judge 模型改 `.env` 的 `LLM_JUDGE_PROVIDER`。

## 5. Leaderboard

实测结果 (n=30，来自 Dev 集)：

| Rank | Model | A | B | C | D | CIEval |
|------|-------|---|---|---|---|--------|
| 1 | 本文 Full+KG | 4.1 | 5.0 | 3.1 | 3.6 | **15.9** |
| 2 | 本文 Full+KG+θ₃ | 4.2 | 5.0 | 2.7 | 3.9 | 15.8 |
| 3 | 本文 Full NoKG | 4.1 | 5.0 | 2.5 | 3.9 | 15.4 |
| 4 | DeepSeek 单体 | 1.5 | 5.0 | 2.3 | 2.6 | 11.3 |
| 5 | MiniMax 单体 | 1.1 | 5.0 | 2.3 | 3.0 | 10.9 |

**关键发现**：
- 多Agent > 单体: 差距 4.6 分
- 单体 LLM 完全不会做文化对比(A=1.1~1.5)
- θ₃ 在 C 维度有 trade-off (2.7 vs 3.1)
- KG 在常规样本上增值有限 (15.9 vs 15.4)
